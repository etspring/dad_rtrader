# DaD: Rogue Trader

Торговый асистент для игры Dark and Darker.

[English](README.en.md)

## Основные возможности

- Поиск на рынке по предмету, редкости, классу, слоту, типу и атрибутам, и покупка лота.
- Тайник: минимальная цена, выставление, быстрая продажа и разбор.
- Свои лоты: снятие с продажи и получение золота.
- Оверлей поверх игры показывает минимальную цену по подсказке предмета.
- Автопокупка и флип по сохранённым правилам.
- Локальный шлюз к игре. В режиме dad_proxy сессия лобби держится и после закрытия клиента.

## Торговля

Вкладка "Автоторговля". Правила хранятся локально и работают, пока программа открыта и есть лобби-сессия. Активные правила проверяются примерно раз в 30 секунд.

Как добавить правило:

1. Запусти шлюз и зайди в лобби игровым клиентом.
2. Выбери вид правила, предмет и редкость. Для травы, зелий и бинтов укажи размер пачки.
3. Кнопка "Обновить инфо" показывает минимальную цену и текущие предложения рынка по этим параметрам.
4. Заполни числа и нажми "Добавить". Правило включается сразу. Колонка "Вкл" останавливает и возобновляет его, "Удалить" убирает.

Виды правил:

- **Автопокупка** - покупает лоты не дороже "Макс. цена покупки", пока в сумке и тайнике не наберётся "Слоты" пачек. "Резерв золота" - сумма, ниже которой золото не тратится.
- **Флип** - покупает так же, затем сам выставляет купленное. Цена лота: минимум чужих лотов минус "Занижение", но не ниже цены покупки плюс "Профит %". Свои активные лоты занимают слоты правила, так что одновременно на руках и на рынке не больше "Слоты" пачек. Для выставления нужен статус Legendary.
- **Автопродажа** - выставляет пачки предмета из сумки и тайника, пока на рынке не будет "Слоты" твоих лотов. "Режим цены": "Фиксированная" ставит "Цену продажи", "Ниже рынка" ставит минимум чужих лотов минус "Занижение". Если чужих лотов нет, в режиме "Ниже рынка" проход пропускается. Для выставления нужен статус Legendary.

Атрибуты у флипа и автопокупки необязательны. Если они заданы, берутся только лоты, где есть все выбранные статичные и случайные атрибуты.

Ветка `master`:

- `manifest.json` - версии программы, контента и списка прокси
- `content/item_labels.json`, `content/attribute_labels.json`, `content/market_filters.json`
- `proxies.json`

Архив не коммитится. Он лежит в GitHub Release у тега из `manifest.json` (`app.tag`, файл `app.file`).

## Минимальные требования

- Windows 10 или новее, 64-bit
- [.NET 10 Desktop Runtime](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe). В архив он не входит.

Оверлей с распознаванием подсказки использует DirectML и нуждается в видеокарте с DirectX 12.

## Установка и обновление

Скачай последний `DadRogueTrader-win-x64.zip` из [GitHub Release](https://github.com/etspring/dad_rtrader/releases).

1. Поставь runtime из списка выше, если его ещё нет.
2. Распакуй архив в отдельную папку. В корне сразу `DadRogueTrader.exe` и остальные файлы, без вложенной папки.
3. Запусти `DadRogueTrader.exe`.

Чтобы обновить, закрой программу и распакуй новый архив в ту же папку с заменой файлов. Настройки остаются в `%AppData%\DadRogueTrader`.
